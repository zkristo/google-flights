# google-flights

A Python toolkit for generating [Google Travel Explore](https://www.google.com/travel/explore) URLs for flights from ~110 European cities to a destination (default: **Paris**).

## What's in this repo

| Path | Description |
|---|---|
| `data/european_airport_cities.json` | Curated list of 110 European cities with IATA codes and country info |
| `data/cities_with_kgmid.json` | Cities enriched with their Google/Freebase Knowledge Graph IDs (`/m/…`) — generated by `resolve_kgmids.py` |
| `scripts/resolve_kgmids.py` | Queries the **Google Knowledge Graph API** to find the `kgmid` for every city in the list |
| `scripts/generate_links.py` | Reads `cities_with_kgmid.json` and produces Google Flights explore URLs for each city → Paris |
| `output/` | Generated JSON + CSV files (git-ignored) |

## Prerequisites

- Python 3.8+
- A [Google Knowledge Graph Search API](https://developers.google.com/knowledge-graph) key

Store your key in a `.env` file at the repo root:

```
GOOGLE_KG_API_KEY=your_api_key_here
```

## Usage

### Step 1 — Resolve kgmids

```bash
python3 scripts/resolve_kgmids.py
```

Reads `data/european_airport_cities.json`, queries the Google Knowledge Graph API for each city, and writes `data/cities_with_kgmid.json`.

### Step 2 — Generate Google Flights links

```bash
python3 scripts/generate_links.py
# or with a custom date:
python3 scripts/generate_links.py --date 2026-06-15
```

Reads `data/cities_with_kgmid.json` and writes:
- `output/cities_to_paris_<date>.json`
- `output/cities_to_paris_<date>.csv`

Each row contains `city`, `country`, `kgmid`, and the full `url` to open Google Travel Explore for that route.

## How the URLs work

Google Travel Explore uses a base64-encoded protobuf (`tfs`) parameter to encode the origin/destination.  
`generate_links.py` decodes a known working template (Zagreb → Europe), replaces the destination with Paris and the origin with each city's kgmid, then re-encodes the result into a valid URL.

## City list

110 European cities spanning all EU member states plus Norway, Switzerland, Iceland, Turkey, the Caucasus, and the Western Balkans.  
See [`data/european_airport_cities.json`](data/european_airport_cities.json) for the full list.
